# Бот Ребилд

Собственный Telegram-бот книжного сообщества. Репозиторий инициализирован для реализации на Rust.

Первая реализация создаётся отдельной веткой с CI и тестами. Исходный Shield24 v0.1.0 на Python остаётся архивным эталоном поведения в Notion, но не является кодом этого репозитория.

**Статус:** разработка; пока не развёрнут в Telegram.
